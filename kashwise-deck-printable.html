Security & Trust

Privacy-First Architecture: Post-Quantum Envelope

Ensuring vulnerable workers and clients never have personal data compromised.

🛡️

Area-Only Public Profiles

Public profiles and gig listings only show broad neighbourhood centres (e.g., “Soweto” or “Orlando”). Exact street addresses and GPS coordinates are never published.

🔐

X-Wing Hybrid Envelope

Phone numbers, real names, and street addresses are encrypted on the user’s device before transmission using ML-KEM-768 + X25519 and AES-256-GCM.

📋

Audited Match Reveal

Decryption only executes server-side when both parties are confirmed matches. Every single contact reveal is logged immutably on the gig’s timeline.

🆔
Private Work ID Handshake
When a gig is accepted, KashWise generates a private Work ID (e.g. KW-7KQ4-M2XP) known only to the matched client and worker.
